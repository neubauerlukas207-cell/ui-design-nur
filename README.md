# Návrh uživatelského rozhraní – HTML a WinForms

Úkoly z předmětu **Návrh uživatelského rozhraní** (VŠPJ, ZS 2025/26): nejdřív webové stránky v HTML/CSS, potom desktopová rozhraní ve Windows Forms. Semestrální práce je zvlášť v [game-catalog-winforms](../../../game-catalog-winforms).

| Složka | Obsah |
|---|---|
| `ukol01-html` – `ukol06-html` | HTML/CSS: struktura stránky, formulář, šachovnice z tabulky, stránka s rozvržením a obrázky |
| `ukol08-kalkulacka` | kalkulačka, kontextové menu |
| `ukol09-winforms` | výběr barev, práce s ovládacími prvky |
| `ukol10-winforms` | galerie obrázků (`PictureBox`) |
| `ukol11-osoby` | evidence osob – menu, seznam, formulář |
| `ukol12-skladacka` | posuvná skládačka z obrázku, časovač |
| `ukol13-winforms` | průhledný úvodní „loading“ screen a přihlašovací formulář |

## Technologie

HTML5 · CSS · C# · .NET Framework 4.7.2 · Windows Forms · Visual Studio

## Jak spustit

- **HTML** – otevřít `ukolNN-html/*.html` v prohlížeči.
- **WinForms** – otevřít `.sln` ve **Visual Studiu 2022** (workload „.NET desktop development“ s .NET Framework 4.7.2) a spustit F5.

## Poznámky

- `ukol01-html` původně obsahoval produktové fotky třetí strany – kvůli autorským právům nejsou v repozitáři.
